# Contributions and ownership

EFSS BellekPad is **not open source**. No public copyright or software
license is offered. See [LICENSE](LICENSE).

**Unsolicited code or creative-asset pull requests are not accepted as a
default contribution workflow.** Please open a discussion about an issue
without including private code, third-party designs or confidential data.

Before any code, documentation, font, icon, artwork, or other copyrighted
material is accepted, the applicable rights holder must confirm permission
and ownership terms **in writing**. A GitHub pull request by itself is not
a transfer of copyright or an additional license grant.

Do not submit security credentials, personal notes, local model files,
Adobe-distributed font files or other materials for which you lack
redistribution rights. General bug descriptions can be considered without
accepting a source-code contribution.

rights and exceptions.
